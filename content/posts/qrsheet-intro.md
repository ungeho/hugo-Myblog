## どんなアプリ？

`QRSheet` は、**複数の文字列からQRコードを作り、対応する文字列と一緒にPDFへまとめるWindows向けGUIアプリ**です。

QRコードをいくつも用意するとき、画像を1枚ずつ作って文書に貼り付けるのは手間がかかります。元の文字列も一緒に並んでいれば、あとから「これは何のQRコードだったか」を確認しやすくなります。その一連の作業を、ひとつの画面でできるようにしたアプリです。

たとえば、資料に載せるURLの一覧や、備品の識別番号、読み取りテスト用の文字列をまとめたい場面で使えます。入力データを外部へ送る処理はなく、QRコードの作成からPDF保存までPC内で行います。

![QRSheetの文字列入力・PDF設定・プレビュー画面](/images/posts/qrsheet/main-window.png)

画面左側が文字列の入力とPDF設定、右側がPDFプレビューです。下部には保存先と生成ボタンがあります。画像は6件の文字列を2列に並べた例です。

## 入手・起動方法

**2026年9月29日時点では、GitHubの公開Releaseはまだありません。** 配布済みのexeをダウンロードする手順ではなく、現在はソースコードから起動する方法を紹介します。

Windows 10 / 11と、64bit版のPython 3.12以降を前提にしています。リポジトリでの動作確認環境はWindows 11 / Python 3.12.10で、Windows 10実機での検証は未実施です。

まず上のGitHubリポジトリで **「Code」→「Download ZIP」** を選んで展開します。展開したフォルダーのうち、`pyproject.toml` と `build.bat` がある場所でPowerShellを開き、次を順番に実行してください。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m qrsheet.main
```

Pythonの別バージョンを使う場合は、`-3.12` をインストールしたバージョンに置き換えます。仮想環境を有効化する操作は不要です。2回目以降は、同じフォルダーで最後の起動コマンドを実行すれば開けます。

## 基本的な使い方

### 1. QRコードにしたい文字列を入力する

左上の入力欄に、**1行につき1件**の文字列を入れます。日本語・英数字・URL・記号を扱えます。

```text
https://example.com/
ABC-12345
テスト用文字列
```

この例では3個のQRコードができます。入力した文字列そのものがQRコードに入り、PDFでは同じ文字列がQRコードの下に表示されます。URL用の表示名を別に指定する形式ではありません。

コピーした一覧は「貼り付け」ボタンか `Ctrl + V` で入力できます。「.txtを読み込む」ではUTF-8形式のテキストファイルを選べます。ファイルの内容で入力欄が置き換わるので、追記したい場合は貼り付けを使います。「入力をクリア」で全体を消せます。

空行や空白だけの行は無視します。一方、有効な行の前後にある空白はQRコードにも保持されるため、不要な空白があれば入力時に取り除いてください。入力欄の右上で対象件数を確認できます。

### 2. 「基本」タブでPDF設定を決める

左側の「PDF設定」には、「基本」と「レイアウト」の2つのタブがあります。まず「基本」で用紙とQRコードの大きさを決めます。

| 設定 | できること |
| --- | --- |
| タイトル | PDFの見出しを指定する。初期値は「QRコード一覧」 |
| タイトルを表示 | 見出しが不要ならチェックを外す |
| 生成日を表示 | 作成日を載せるかどうかを切り替える。任意の日付を入力する設定ではない |
| 用紙サイズ | A4 / Letterを選ぶ |
| 用紙方向 | 縦 / 横を選ぶ |
| QRコードサイズ | 20〜60mmで調整する。初期値は35mm |
| カラム数 | 横に並べる列数を「自動」または1〜4列から選ぶ |

初めてなら、A4・縦・35mm・自動のまま入力して、プレビューを見ながら調整すると分かりやすいです。日付とタイトルは初期状態では表示され、ページ番号も付きます。

### 3. プレビューを見ながら配置を調整する

入力や設定を変えると、操作が止まって約0.5秒後に右側のプレビューが自動更新されます。「プレビューを更新」で手動更新もできます。

**プレビューには実際に生成したPDFを表示しますが、この時点では指定した保存先にPDFは保存されません。** 複数ページになる場合は、プレビューをスクロールして続きも確認できます。

カードの位置や余白を変えたいときは「レイアウト」タブを使います。具体的な調整方法は後半で紹介します。

### 4. 保存先を確認してPDFを生成する

画面下部の「PDF保存先」を確認します。初期状態ではWindowsの **「ドキュメント\QRSheet」** へ保存され、フォルダーがなければ初回保存時に作成されます。ドキュメントをOneDriveなどへ移している場合は、その場所に従います。

普段使う保存先を変えるには「変更…」からフォルダーを選びます。選んだ場所は次回起動時にも復元され、「既定に戻す」で標準の保存先へ戻せます。

**「PDFを生成」** を押すと、そのフォルダーへ `QRSheet_2026-09-29.pdf` のような日付付きの名前で保存します。同名ファイルがあれば `_001`、`_002` のような連番を付けるので、この操作では既存PDFを上書きしません。

ファイル名や今回だけの保存場所を指定したいときは「名前を付けて保存…」を使います。こちらで既存ファイルを指定した場合は、上書き確認の内容を確認してください。

生成中は進捗が表示されます。その途中で入力を編集しても、実行中の保存内容には反映されないため、変更後の内容が必要なら完了してから再生成します。

### 5. 完成したPDFを確認する

完了メッセージが出たら、「PDFを開く」で関連付けられたPDFビューアーを開けます。「保存先フォルダーを開く」では、保存したPDFのあるフォルダーを開けます。

![QRSheetで生成した、文字列付きQRコード6件のPDF例](/images/posts/qrsheet/pdf-sample.png)

上は既存の検証用PDFを画像化したものです。QRコードと元の文字列がカードごとにまとまり、長いURLは折り返して表示されます。件数が増えて1ページに収まらない場合は、行を途中で分割せずに改ページします。

## カードの配置を用途に合わせて変える

`QRSheet` では、QRコードを並べるだけでなく、**紙のどこに、どれくらいの間隔で置くか**を調整できます。「PDF設定」の「レイアウト」タブで設定します。

### 横方向と縦方向を組み合わせる

| 方向 | 選べる配置 | 使い方の例 |
| --- | --- | --- |
| 横方向 | 左詰め・中央・右詰め・均等配置 | 左から一覧として並べる、カード群を中央へ寄せる |
| 縦方向 | 上詰め・中央・下詰め・均等配置 | 上から詰めて並べる、少数のカードをページ中央へ置く |

初期値は「左詰め・上詰め」です。「中央・中央」にすると、各ページのカード群を使える領域の中央へ寄せられます。カード内の文字を中央揃えにする設定ではありません。

「均等配置」は、余ったスペースを列と列、行と行の間へ振り分けます。カード自体を引き伸ばすわけではなく、設定した間隔が最小の間隔になります。列や行が1つだけの場合は、左・上に揃います。

縦方向の配置が変わるのはタイトル・日付の下からページ番号の上までの領域で、見出しやページ番号は移動しません。また、最終行のカードが少なくても、同じページの列位置を保ちます。

### カード間隔とページ余白

カード間隔は横・縦を別々に、ページ余白は上・下・左・右を別々に指定できます。いずれも **0〜100mmの整数**で、初期値はカード間隔が5mm、四辺の余白が15mmです。

たとえば、カードの間を広めに取りたいなら横・縦間隔を増やします。紙の端から離したい場合はページ余白を増やします。初期値から少しずつ変え、プレビューで全体のバランスを見るのが扱いやすいです。

### QRサイズとカラム数の関係

カード幅は **「QRコードサイズ＋4mm」** で決まります。「自動」の列数は、この幅と横間隔・左右余白をもとに、最大4列までで計算します。

QRコードを大きくすると、そのぶん横に置ける数は減ります。手動で4列などを指定して用紙に収まらない場合は、勝手に小さくせずエラーを表示します。列数や横間隔を減らす、余白を調整する、用紙を横向きにする、といった方法で見直してください。

設定を戻したくなったら「初期値に戻す」を押します。**「基本」「レイアウト」の両方**が初期値へ戻り、保存されます。保存先を戻す「既定に戻す」とは別の操作です。

## 次に使うときの設定と、現在の制限

PDFの設定はプレビュー・PDF生成時やアプリ終了時に保存されます。毎回同じ用紙や配置を使うなら、次の起動でもその設定から始められます。一方、**QRコード用の入力文字列は保存しません。** 再利用する一覧は、UTF-8のテキストファイルとして手元に残しておくと便利です。

使ううえで知っておきたい制限もあります。

- 1回に生成できるのは最大10,000件、読み込むテキストファイルは10MBまでです。
- 長い文字列ではQRコードが細かくなります。「QRが細かすぎます」と出たら、QRサイズを大きくするか文字列を短くしてください。QR自体の容量を超える場合もエラーになります。
- PDF上の長文は折り返し、必要に応じて文字サイズを小さくします。それでも1ページに収まらない内容はエラーになります。
- 絵文字など、使用中の日本語フォントにない文字はエラーになります。通常はWindowsの日本語フォントを利用します。
- CSV / Excelファイルの直接読み込み、生成中のキャンセル、インストーラー、実行ファイルの署名は未実装です。

印刷して使う場合は、必要なサイズで出力し、実際に使う読み取り機器で確認しておくと安心です。

## 技術的な構成とexeのビルド

中身はPythonのアプリで、主に次のライブラリを使っています。

| 技術 | 役割 |
| --- | --- |
| Python | 入力処理やアプリ全体の処理 |
| PySide6 / Qt PDF | 日本語GUIとPDFプレビュー |
| qrcode | 入力文字列からQRコードを生成 |
| ReportLab | QRコードと文字列をPDFへ配置 |
| PyInstaller | Windows向けexeのビルド |

PDF内のQRコードは画像を拡大して貼る方式ではなく、黒い矩形をベクターとして描画しています。日本語フォントはWindowsから読み込み、使用する文字をPDFへ埋め込みます。

exeを自分で作る場合は、先ほどのセットアップ後、リポジトリ直下で次を実行します。

```powershell
.\build.bat
.\dist\QRSheet\QRSheet.exe
```

ビルド結果は `dist\QRSheet\` にまとまります。**exeだけを取り出さず、フォルダー全体を使う必要があります。** フォルダーごと受け取って使う側にはPythonのインストールは不要です。現時点で公開Releaseから入手できる配布物ではなく、自分でビルドする手順です。

## AI補助での開発について

開発では、要件整理、実装、修正、PDFのレイアウト調整をAIコーディング支援と対話しながら進めました。どんな一覧が欲しいか、配置を変えたときにどう見えるかを確認しながら、操作と出力を詰めていく形です。

`QRSheet` でやりたかったのは、文字列の一覧を入れたら、内容を確認しやすいQRコードの一覧PDFにできることです。用紙や配置をプレビューで調整できるので、印刷用の一覧を繰り返し作るときにも使いやすいと思います。
